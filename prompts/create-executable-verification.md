# Create executable verification

Using .ai/VERIFICATION.md and the tools already present in this repository, create the smallest useful executable checks. Reuse existing commands and CI definitions. Do not add a dependency for appearance or hide failures.

Provide a read-only preflight check for relevant prerequisites, a fast development check, and a full check for significant changes where those distinctions help. Avoid duplicating equivalent commands. Update .ai/VERIFICATION.md with the actual commands, coverage, and limitations.
