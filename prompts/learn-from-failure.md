# Learn from failure

[INCIDENT OR REWORK]

Briefly record the symptom, underlying cause, and smallest plausible preventive action. Consider misunderstanding, ambiguous criteria, inadequate context or plan, missing tests or checks, excessive permission, review gaps, and architecture. Prefer a targeted test or executable check when it can enforce the invariant. Avoid adding a rule from an isolated failure without evidence it would help.
