# FEATURE Workflow

> Extends [the method](../METHOD.md) for adding or extending user-visible behavior.

## Before BUILD

Identify the user or system need and the observable outcome. Distinguish required behavior from optional design ideas. Check existing behavior, interfaces, compatibility expectations, and affected user journeys. Surface materially different product or UX options and their trade-offs for human choice.

For M/H work, define acceptance criteria for the normal path, important edge cases, and relevant failure behavior. Plan a small usable slice when possible.

## Expected evidence

Show that the intended behavior works through the relevant interface, existing behavior still works, and each material acceptance criterion has supporting evidence. Record any rollout or compatibility concern that remains.
