## Review and acceptance

Two independent read-only reviews examined the supplied-image change. One verified the artwork hash, screenshots, crop bounds, manifest scope, and code cleanup. A second reviewed the final focus guard and found no blocking defect. Their findings led to these corrections: the fixture-only fallback no longer contacts an ordinary site's `/input/background.png`; the local server serves PNG as `image/png`; `npm run check` parses the manifest; and both the source PNG and packaged copy are included so a clone can run the preview.

The final browser smoke test after those corrections reported `data-world-ready=true`, five DOM platforms, zero helpers, zoom `1.062` at a 720-pixel viewport, and no remaining game/world/style nodes after Escape. `npm run check` and `git diff --check` pass. The full traversal and win evidence was recorded before the fallback correction, which did not change physics or route selection.

Known limits: late-inserted dark text may lack contrast adjustment; an image load failure leaves a dark fallback canvas; actual toolbar activation on an unrelated site remains unverified.
